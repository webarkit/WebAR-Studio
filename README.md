# WebAR Studio
> [!IMPORTANT]
> **WebAR-Studio is being superseded by [WebARKit Studio](https://github.com/webarkit/webarkit-studio).**
>
> WebARKit Studio is a new node-based WebAR authoring tool, rewritten from scratch:
> a [Rete.js](https://retejs.org) node editor, a lightweight player running
> [JsartoolkitNFT](https://github.com/webarkit/jsartoolkitNFT) with Three.js or Babylon.js,
> and export of the graph as a standalone app.
> It shares no code with this repository and uses a different project format.
>
> This repository stays available for reference. New features and fixes go to
> [webarkit/webarkit-studio](https://github.com/webarkit/webarkit-studio).

Bring your dreams to live with WebAR Studio. Pictures, postcards, business cards, anything can come to life using WebAR Studio.
This is a full 3D, WebGL editor which includes the capability to create Apps with image tracking (NFT tracking).
